# 栖语 Qiyu · 交付日志

## v1.0.0 — 2026-10-26

### 交付范围

- 产品名统一为 **栖语 Qiyu**
- 全新品牌图标（深青底 + 对话气泡 + 小鸟 + 树枝）
- 清空全部内置/测试角色，出厂为角色工坊空状态
- 项目文档、架构说明、交接文档、使用说明、第三方许可整理
- Windows 安装包（Inno Setup）
- Git 仓库清理、提交、tag 与 Release

### 主要改动

#### 安装包与配置硬化

- 安装包内默认 LLM/Letta 地址改为 localhost 示例，移除私有局域网地址
- 确认安装包不含 `wechatauto_channel.py`、旧 spec、测试报告或角色数据
- 安装包实际安装/卸载测试通过

#### 角色与头像

- 移除 16 个 MBTI 测试角色及用户测试角色
- 出厂 `characters/_user_characters.json` 为空，`characters/default.json` 为空
- 头像库从重复的 PNG + SVG 统一为 SVG
- 删除 24 个重复 PNG：`a01–a12.png` + `default_01–default_12.png`
- 新增 12 个女性向头像 `a13–a24`，保持 Notionists 黑白线稿风
- 头像选择器 24 个选项，无重复
- 角色卡、聊天头像、设置头像统一走 `.svg`

#### UI

- 协议弹窗背景修复（之前 `--bg-primary` 不存在导致透明）
- 协议滚动区/底部确认区重新布局
- 进入外部通讯页自动弹出长协议
- 协议未滚动到底不能勾选/确认
- 项目名称与窗口标题更新为「栖语 Qiyu」
- 窗口/任务栏图标使用新品牌图标；打包内和 sidecar 都带 ico/png

#### 人设生成

- 修复外部路由未配置 Key 时 401 不可用的问题，自动回退本地模型
- 角色生成 token 上限 6000
- 反 AI 味提示词：普通姓名、具体生活、真实缺点、关系摩擦、口癖
- 生成后自然语言 `buildPersonaText()`，不再把结构化简历原样塞进 persona
- 名称去重：同一进程内避免连续重复姓名

#### 记忆与聊天

- 聊天流式 partial 不提前播放，最终按 `assistant_messages` 一次播放，修复重复气泡
- 自动总结器同一日期/角色只保留一份 daily outline
- 连续重复消息不进入总结，减少“用户连说好几声你好”的幻觉
- 角色/用户记忆测试通过

#### 外部通道

- 移除 `wechatauto` 本机微信窗口接管
- 保留 ClawBot、企业微信、QQ、飞书
- 新增 `tests/test_external_channels_contract.py`
- 6/6 mock 合同测试通过：token、发送 payload、缺配置、HTTP 失败、飞书 Webhook
- 真实平台凭证/公网回调仍未配置；不伪造“已连接”
