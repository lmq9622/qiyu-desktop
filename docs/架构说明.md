# 栖语 Qiyu · 架构说明

> 适用版本：v1.0.0  
> 读者：接手开发、打包、发版和排查问题的人

## 2. 启动链路

1. `client.py` 设置 `QIYU_PORT`、`QIYU_DATA_DIR`，启动后端子进程。
2. 后端 `demo.py` 加载 `config/settings.yaml`、运行时设置、角色、记忆和知识库。
3. `client.py` 轮询 `/health`，确认后端可用。
4. 创建 PyWebView `edgechromium` 窗口，加载 `http://127.0.0.1:8765/`。
5. 通过 Win32 `WM_SETICON` 设置窗口图标；图标来自 sidecar `assets/icon.ico`，打包内也有兜底。

## 3. 角色与提示词

角色由 `characters/` 加载：

- `characters/default.json`：出厂默认为空
- `characters/_user_characters.json`：用户创建角色，出厂为空
- `Character` 字段：`name/tagline/description/persona/human/memory_prompt/speech_style/tools/keywords/avatar/resume/persona_params`

AI 角色生成：

- `companion/settings.py::build_resume_prompt` 生成结构化 11 字段简历
- `companion/llm.py::generate_character_card` / `_stream` 调用路由模型
- 路由模型未配置 Key 时回退本地主模型；不会静默 401
- 生成后前端 `buildPersonaText()` 把简历整理成自然人格描述，不把结构化字段直接塞进 `persona`

## 4. 聊天链路

`POST /v1/chat/completions`：

1. 根据 `user` 找到当前选择角色（前端先调用 `/v1/characters/select`）。
2. 合并用户消息，写入 `mem_mgr` 与 `runtime.db.unified_store`。
3. 组装系统提示：角色卡、记忆、RAG、关系、行为约束。
4. 调用 LLM；流式时 SSE 返回 `assistant_messages` 增量事件。
5. 最终消息按 `pieces` 存为多气泡；前端只播放最终稳定事件，避免 partial JSON 重解析造成重复。
6. 异步运行记忆流水线，做事实抽取、当天大纲、全天总结。

## 5. 记忆与知识库

- 记忆存储：`memory/` 的 `MemoryManager`，本地 JSON + numpy 向量
- 短期记忆：`short_term`
- 长期记忆：`long_term`
- 当天大纲：`outlines/<user>__<char>___<date>.json`
- 全天总结：`full_day_summary`
- 自动总结器按 `(user_id, char_id, date)` 幂等；重复调用会替换旧 daily outline，不再堆叠
- 知识库：`rag/`，支持文档上传、索引、检索；本地向量存储

## 6. 外部通讯

`channels/` 统一 `BaseChannel`：

| 通道 | 发送链路 | 接收 |
|---|---|---|
| ClawBot | 扫码/第三方 iLink | 视通道而定 |
| 企业微信 | `gettoken` → `message/send` | 需公网回调 |
| QQ | `getAppAccessToken` → `/v2/users/<openid>/messages` | 事件订阅 |
| 飞书 | `tenant_access_token` / Webhook | 事件订阅 |

安全边界：

- 不内置任何真实凭证
- 设置页有长版用户协议/免责声明，必须滚动到底部确认
- 没有凭证时通道显示待配置，不伪造连接成功
- 合同测试使用本地 mock 端点，不访问真实平台

## 7. 数据与安全

- 默认数据目录：`~/.ai_companion/data`
- 后端只监听 `127.0.0.1`
- 配置中的 API Key 只保存在本机；仓库不提交 `config/settings.yaml` / `.env`
- 日志、备份、模型权重、dist/build/backups 不进 Git
- 外部分享日志前需脱敏 Token、AppSecret、手机号、OpenID、聊天内容

## 8. 构建与安装

```bash
python build.py
# 输出 dist/Qiyu/Qiyu.exe + sidecar

ISCC.exe installer\Qiyu.iss
# 输出 dist/installer/Qiyu-Setup-1.0.0.exe
```

构建产物不入 Git；安装包只包含当前 `dist/Qiyu`，不包含旧 spec、测试数据、备份和用户配置。

