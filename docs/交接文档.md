# 栖语 Qiyu · 交接文档

> 版本：v1.0.0  
> 目标：接手的人读完这一份能启动、改代码、跑测试、打包、发版。

## 1. 30 秒上手

```powershell
cd D:\Codex projects\qyu-chat
python -m pip install -r requirements.txt
python demo.py            # 后端 http://127.0.0.1:8765
python client.py          # 桌面窗口
```

开发前端时可以只开 `demo.py`，用浏览器访问；改 `gateway/static/index.html` 后刷新即可。

## 3. 目录职责

| 路径 | 说明 |
|---|---|
| `client.py` | PyWebView 窗口，启动/停止后端，图标兜底 |
| `demo.py` | FastAPI 主后端，所有主要 API |
| `companion/` | LLM 客户端、提示词、行为、关系、调度 |
| `gateway/` | 前端静态文件与路由 |
| `memory/` | 记忆、摘要、当天大纲 |
| `rag/` | 知识库索引/检索 |
| `channels/` | 外部通讯通道 |
| `characters/` | 角色加载；`*_user_characters.json` 出厂为空 |
| `runtime/` | Provider、模型、设备、日志 |
| `assets/` | 品牌图标/logo |
| `installer/` | Inno Setup 脚本 |
| `docs/` | 项目简介、架构、交接、交付日志、使用说明 |
| `tests/` | 单测与合同测试 |

## 4. 配置

- `.env.example` 是模板，`config/settings.yaml` 是本地运行时配置，**不进 Git**。
- 数据目录默认 `~/.ai_companion/data`，可用 `QIYU_DATA_DIR` 覆盖。
- 主要配置：LLM base_url/model、路由模型、Embedding、RAG、外部通道凭证。
- 不要把 API Key、AppSecret、Token、Webhook 写进 README、截图或提交记录。

## 5. 测试

```powershell
python -X utf8 -m unittest discover -s tests -p "test_*.py"
python -X utf8 test_harness\check_js.py   # 如果该脚本存在
```

```powershell

```

输出 `dist/Qiyu/Qiyu.exe` + sidecar。检查：

```powershell
Test-Path dist\Qiyu\Qiyu.exe
Test-Path dist\Qiyu\assets\icon.ico
Test-Path dist\Qiyu\assets\logo.png
Test-Path dist\Qiyu\_internal\gateway\static\channel_legal.txt
```

## 7. 安装包

```powershell
& "C:\Users\<you>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer\Qiyu.iss
```

输出 `dist/installer/Qiyu-Setup-1.0.0.exe`。

安装测试建议安装到临时目录：

```powershell
Qiyu-Setup-1.0.0.exe /VERYSILENT /DIR="%TEMP%\QiyuInstallTest" /NORESTART
```

然后启动 `%TEMP%\QiyuInstallTest\Qiyu.exe`，检查 `/health`、角色空状态和窗口图标，再卸载。

## 9. 已知限制

- 外部通道需要真实企业/平台凭证，当前仅完成 mock 合同验收。
- 公开回调需要公网地址/HTTPS/备案；桌面版本机默认没有公网回调。
- 安装包不做代码签名，Windows SmartScreen 可能提示未知发布者。
- 出厂无角色，这是有意设计；首次使用必须创建角色。
- AI 生成内容仍需审核；医疗/法律/金融等高风险场景不能只依赖模型。
