# 栖语 Qiyu 使用说明

> 对应界面：「使用说明」板块（左侧导航第 4 项）。这份是仓库里的同内容版本，方便离线查看。

## 一、3 分钟上手

1. **配模型**：设置 → LLM 设置 → 填「API 地址」（以 `/v1` 结尾）和「API Key」→ 点「刷新列表」→ 选模型 → 点「验证配置」→ 保存。
2. **建角色**：角色工坊 → 出厂为空状态，用 AI 生成或手写名字/性格/关系 → 选头像 → 保存。
3. **开始聊**：回到「对话」，左上角选中角色，直接发消息。
4. **备份**：知识与记忆 → 「导出角色」，得到一个 `.qy3f` 文件，存网盘。

## 二、推荐使用流程（按这个顺序最省事）

1. **先把模型配通，再建角色。** 模型没通就建角色，后面聊不动会以为是角色坏了。
2. **一个角色固定一个模型。** 频繁换模型，说话风格和记忆表现会飘。
3. **先聊 10 轮再看记忆。** 记忆是后台异步整理的，刚开始空是正常的。
4. **每周导出一次角色包。** `.qy3f` 是唯一完整备份（人设 + 记忆 + 知识库 + 世界状态）。
5. **换电脑**：旧机「导出角色」→ 新机「导入角色」；要连聊天记录一起带走，再拷贝数据目录。
6. **地址和 Key 必须是一家的。** 不要用 A 家的地址配 B 家的 Key，否则一定 401/404。

## 三、常见问题（FAQ）

### 模型

**Q：模型列表刷新不出来 / 一直是旧模型？**
刷新会按设置页当前填的「API 地址 + Key」去查 `/models`；连不上会直接提示失败原因，不会编造模型，旧模型也不会硬塞进下拉。确认地址以 `/v1` 结尾、Key 与地址属于同一家。

**Q：聊天提示「LLM 服务未配置或不可用」？**
后端连不上你填的模型服务。检查：① 地址能否在浏览器打开 `/models`；② Key 是否正确；③ 模型名是否在服务端存在。改完点「验证配置」。

**Q：列表里没有我要的模型？**
在「模型选择」下方的「自定义模型名」输入框直接填模型名（接口不支持 `/models` 时用这个）。

**Q：本地中枢不需要 Key，怎么填？**
API Key 留空即可，地址填到 `/v1`。即使中枢不实现 `/models` 也能正常聊天；刷新失败时手动填模型名即可。

**Q：快速接入的预设里有模型，聊天却报错？**
预设只负责填地址和候选模型，Key 要填对应平台的；「地址 + Key + 模型名」三件套必须匹配。

### 记忆

**Q：记忆面板是空的 / 她记不住我说的话？**
记忆在聊天后异步写入，刚装好或刚建角色时为空正常。聊几轮后点面板右上角刷新；也可以手动加一条试试。

**Q：怎么删除记忆？**
记忆面板可单条删除或清空该角色记忆库。删除不可撤销，建议先导出角色包。

### 角色包（qy3f）

**Q：导入角色失败？**
只支持本应用「导出角色」生成的 `.qy3f` 文件。其他格式（包括改了后缀的文件、别的软件导出的文件）都不支持。

**Q：导出的包能给别人吗？**
能，但 `.qy3f` 不加密：人设、记忆、知识库都在里面，谁拿到都能看。带隐私记忆的包不要外发。

**Q：换电脑怎么迁移？**
轻量：旧机「导出角色」→ 新机「导入角色」。完整：再把 `data` 目录整体拷过去（含聊天记录、关系、情绪）。

### 数据与故障

**Q：数据存在哪里？**
默认 `%USERPROFILE%\.ai_companion\data`（开发模式在项目根 `data/`）。整个目录拷走就是全量备份。

**Q：打开白屏 / 端口被占用？**
默认端口 8765。被占用时设环境变量 `QIYU_PORT` 换一个；白屏先看 `%USERPROFILE%\.ai_companion\client.log` 和 `backend.log`。

**Q：会不会把聊天上传到别处？**
不会额外上传：只有你配置的 LLM 地址会收到对话内容；角色、记忆、日志都在本机。API Key 以明文存在数据目录，别把该目录同步到公共网盘。

**Q：语音、微信、企微、QQ、飞书能用吗？**
语音还在测试；微信/企微/QQ/飞书代码已接好，但需要填自己的凭证，在「设置 → 外部通讯」里点自检。

**Q：界面能换主题 / 深色吗？**
设置 → 外观，可切主题与深色。

### 角色表现

**Q：角色说话像客服 / 不像人？**
检查角色卡的「说话风格」和「红线」；默认人格提示词约 2 万字，已做口语化。也可以在角色工坊把「性格 / 互动方式 / 说话风格」调具体一点。

## 四、出问题先看这三处

1. 服务是否活着：浏览器打开 `http://127.0.0.1:8765/health`，应返回 `{"status":"ok"}`。
2. 客户端日志：`%USERPROFILE%\.ai_companion\client.log`（启动/窗口问题）。
3. 后端日志：`%USERPROFILE%\.ai_companion\backend.log`（模型/接口报错）。
