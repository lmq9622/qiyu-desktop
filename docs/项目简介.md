# 栖语 Qiyu · 项目简介

## 一句话

栖语 Qiyu 是一个**本地优先的 Windows AI 陪伴桌面应用**：角色、记忆、知识库和聊天记录默认留在本机，用户可以自己创建有真实缺点、关系和说话方式的角色，并对外部通讯通道做显式配置。

## 它解决什么问题

很多“AI 伴侣”项目只做一层聊天 API 包装：角色是几行形容词，记忆靠上下文硬塞，所有用户看到同一套模板。栖语把问题拆开：

1. **角色先像一个具体的人**：姓名、年龄、职业、城市、租金/通勤、生活物件、真实缺点、关系摩擦、说话口癖，而不是“温柔、清醒、独立”的形容词堆砌。
2. **记忆有层次**：短期事实、长期记忆、当天大纲、全天总结分开管理；总结器去重，不重复堆大纲。
3. **聊天像微信，不像客服台**：流式回复、多气泡、短句、平级关系；不把内部推理展示给用户。
4. **外部通讯是显式选择的扩展**：企业微信、QQ、飞书、ClawBot/第三方扫码通道都要自己申请凭证；没有凭证就不假装“已打通”。

## 当前版本

- 版本：**v1.0.0**
- 平台：Windows 10/11 x64
- 形态：PyWebView 桌面窗口 + `127.0.0.1:8765` 本地 FastAPI
- 出厂角色：**0 个**。首次启动为角色工坊空状态，需要自己创建。
- 内置头像：24 枚（12 枚新增女性向造型）
- 测试基线：**195 个测试通过**

## 核心模块

| 模块 | 负责 |
|---|---|
| `client.py` | 桌面窗口、后端进程、窗口图标 |
| `demo.py` | FastAPI 主服务、OpenAI 兼容聊天端点 |
| `companion/` | LLM 适配、提示词、行为、关系、调度 |
| `memory/` | 短期/长期记忆、当天大纲、总结去重 |
| `rag/` | 本地知识库文档索引与检索 |
| `channels/` | 企业微信、QQ、飞书、ClawBot 通道 |
| `gateway/static/` | 单页 Web UI、头像、长协议文本 |
| `characters/` | 角色加载；出厂 `characters` 为空 |
| `installer/` | Inno Setup 安装包脚本 |

## 不做什么

- 不提供平台账号、企业资质、AppID/Secret 或公网回调
- 不承诺第三方通道永久可用或不被封禁
- 不把 AI 生成内容当作医疗、法律、金融或税务意见
- 不默认上传用户聊天数据到本项目的服务器

## 适合谁

- 想在自己电脑上跑一个长期陪伴角色的人
- 想研究角色提示词、记忆分层、RAG 和本地模型编排的开发者
- 想用企业微信/QQ/飞书做自己业务机器人，并愿意自己完成平台审核与合规配置的团队
